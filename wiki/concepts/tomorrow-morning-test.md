# Tomorrow-morning test

> Raw: [enforcement lessons](../../raw/design-notes/2026-10-04-enforcement-lessons.md)

## Overview

Before adding a number to a canon page, ask: would this be wrong tomorrow morning without anyone doing anything wrong? If yes, a report owns it. Write the rule and link the report instead.

## Start here (as of 2026-10-04)

- Fails the test: a daily position, a running total, a queue length. These belong to whatever generates them.
- Passes the test: a threshold, an annual target, a published calendar. Only a decision changes these, and a decision is something to [[ingest]].

## Why

A page that raced a nightly report lost every morning. The same session that updated it left it stale by the next refresh. [raw](../../raw/design-notes/2026-10-04-enforcement-lessons.md) See [[page-zones]] for where numbers that pass belong.
