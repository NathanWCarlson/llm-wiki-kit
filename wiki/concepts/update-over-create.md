# Update over create

> Raw: [enforcement lessons](../../raw/design-notes/2026-10-04-enforcement-lessons.md)

## Overview

Edit the page that owns an idea instead of starting a new one. This is the rule agents break most, because creating a page always feels safer than rewriting someone else's.

## Start here (as of 2026-10-04)

A new page needs one of:

- a new entity (a system, process, team or place the wiki has never described),
- a new question,
- a new axis that no existing page covers. Rare, and the log entry should say why.

Everything else is an edit. Check [[canon-map]] for the home first.

## Signs it was broken

- `thing-v2.md` or `thing-updated.md`
- Two pages whose first paragraphs say the same thing
- A table that appears on more than one page

Fix it in the [[hygiene-pass]]: merge into the canon page and leave a link. Related: [[supersede-in-place]].
